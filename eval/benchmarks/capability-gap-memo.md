# P0 capability-gap memo

The three timed HTML animatics are approval targets, not new public authoring
APIs. This memo maps every target moment to the smallest compositor or primitive
capability needed to reproduce it deterministically. Anything absent from this
mapping is outside the P3/P4 contract.

## shipcheck · `readme-loop`

| Target moment | Required capability | Phase |
| --- | --- | --- |
| Direct hook inside the terminal | Kinetic text object; shot enter/exit windows | P3/P4 |
| Terminal output and checklist coexist | Named hero/supporting slots; embedded terminal product surface | P3 |
| 3/3 result replaces the blocked state | Semantic state transition; hero metric/text object | P3 |
| Final result remains readable before restart | Payoff hold plus profile-aware loop transition | P3 |

## Fixed initial primitive set

The memo selects the smallest initial set needed by the revised targets:
kinetic text, logo lockup, persistent product surface/device, named layout
slots, semantic UI state changes, a chart path, and a hero metric. Cursor
objects, floating perspective surfaces, orbit/sonar motifs, a general object
grid, before/after primitives, and unrestricted feature-callout APIs are not
part of the P3/P4 contract.
